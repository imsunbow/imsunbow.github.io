- **온보딩 AI 챗봇**: PP 모듈 업무 지식에 쉽게 접근할 수 있는 도구를 개발했습니다.
- **모니터링 대시보드**: 운영 현황을 확인할 수 있는 대시보드를 개발했습니다.
